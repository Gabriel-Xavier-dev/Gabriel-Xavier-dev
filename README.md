# Hi, I'm Gabriel! 👋

**☕ Backend Developer (Java) | 💻 Information Systems | 📱 Android**

I am an Information Systems student (7th semester) with a strong focus on backend
development and building robust REST APIs. My specialty lies within the Java
ecosystem, where I develop scalable solutions using **Spring Boot** and manage
data persistence with **PostgreSQL and MySQL**.

I work extensively with databases: designing schemas, writing and optimizing SQL
queries, modeling relationships between entities, and integrating the data layer
with backend applications. I am also a strong advocate for clean code, solid
architectural patterns like **MVC and layered architecture**, and standardized
version control practices using **Git and GitHub**.

Besides backend, I build **Android applications with Kotlin** and automate
workflows with **n8n**, which lets me understand the full flow between data,
APIs and the clients that consume them. I value technical excellence and believe
that a well-structured, maintainable backend is the foundation of any great
application.
